# analyze-source 변경 이력

## v2 — 2026-04-07

**하네스 편향 제거 + 범용 라우팅 재설계** (breaking change)

- **트랙 차원 도입**: `harness` / `model` / `ax` 세 트랙. 애매한 경우 `?`.
- **폴더 물리 분리**: `insights/analysis/{track}/파일명.md`
- **템플릿 분리**: 트랙별 전용 템플릿 (`analysis-note-{harness,model,ax}.md`)
- **범용 평가 루브릭**: 5항목 재설계
  - `인사이트_유용성` → `인사이트_밀도`
  - `계층_분류` → `계층_자연성`
  - `실행_가능성` → `부가가치` (하네스 특화 제거)
  - `근거_충분성` → `근거_강도` (A 깊이에서도 논리 일관성으로 채점)
  - `연결_의미성` → `연결_품질`
- **트랙 delta 섹션**: harness → "하네스 적용 제안", model → "기술 의미", ax → "도입 조건"
- **`harness_applicable` 필드 제거**: `track` 으로 대체
- **references/tracks.md 신규**: 트랙 정의·판별 알고리즘
- **기존 48건(39 source + 9 repo) 마이그레이션 완료**: harness 26 / model 6 / ax 16
- 92개 파일의 wikilink 경로 일괄 갱신
