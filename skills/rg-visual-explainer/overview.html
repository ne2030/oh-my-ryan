Skill Architecture Overview

rg-visual-explainer 스킬 구성도

공통 기본 원칙(조건부 1턴 인터뷰·독자 기준 번역·1장면 콘티 <desc>·디폴트 퀄리티+톤 변주)과 유형별 적용 규칙(원인 해부 / 시스템·아키텍처 / 수치·비교)을 2계층으로 분리하고, 자동 린트와 7대 검수 게이트로 마감하는 범용 시각화 스킬입니다.

버전: 1.3.0 관리 원본: skills/rg-visual-explainer/ 설치기: scripts/install-rg-visual-explainer.mjs 배포 대상: ~/.codex/skills · ~/.claude/skills

1. 폴더 구조와 배포 경계

skills/rg-visual-explainer/ 폴더는 에이전트가 실행할 때 읽는 런타임 묶음과 품질 회귀를 추적하는 평가 아카이브(evals/)로 나뉩니다. 전역 설치기(install-rg-visual-explainer.mjs)는 런타임 묶음의 SHA-256 해시를 계산해 ~/.codex/skills와 ~/.claude/skills에 배포하고, 영수증(INSTALLATION.json)으로 일치 여부를 검증합니다.

2. 실행 워크플로우: 목적·독자 점검 → 콘티 설계 → 7대 게이트 검수 루프

도형을 배치하기 전에 1단계에서 목적·독자·톤(모호할 때만 1턴 인터뷰)과 인과·전제를 먼저 확인합니다. 그다음 <desc> 1장면 콘티와 유형별 규칙으로 조립한 뒤, 자동 린트와 렌더링 스크린샷으로 충돌 0건 + 7대 게이트(독자 반문 테스트 포함)를 통과해야 완료됩니다.

3. 핵심 설계 원리: 금지하는 실패 패턴 vs v0.9 자유 합성

반복 관찰된 실패는 세 가지였습니다: ① 문장을 3중 테두리 박스 안에 가두기, ② 공용 함수로 수십 개 항목을 일괄 찍어내기, ③ 내부 용어만 던지고 중간 인과 고리를 생략하기. 0.9.x는 이 세 가지를 차단하고, 목적에 맞는 장면·미니 화면·슬롯의 자유 합성을 표준으로 삼습니다.

4. 버전 진화 이력 (0.1.0 → 1.3.0)

실패 사례(BAD-001~005), 블라인드 Claude·Gemini 평가, 포트폴리오·이슈 보드 실전 테스트 피드백을 바탕으로 단계적으로 진화했습니다.

5. 파일별 역할 및 7대 검수 게이트 요약

파일 경로 구분 역할
SKILL.md 런타임 스킬 진입점. 1.3.0 2계층 핵심 흐름(공통 원칙 · 유형별 규칙 · 린트/검수)을 안내합니다.
core.md 런타임 0절(조건부 1턴 인터뷰·독자 납득 3원칙) + 1절(1장면 콘티) + 1-B절(원인/시스템/수치 유형별 규칙) + 2~5절(역할 분리·디폴트+톤 변주·린트/렌더 검수).
references/visual-gate.md 런타임 렌더 스크린샷을 보고 판정하는 7대 검수 게이트(충돌 0건, 글/그림 분리, 1장면 콘티, 유형별 규칙, 색 절제, 톤 일관성, 독자 반문 테스트).
overview.html 런타임 스킬 자체의 폴더 구조, 실행 루프, 핵심 원리, 버전 진화를 한눈에 보여주는 구성도 문서(업데이트 시 함께 갱신).
scripts/lint-visuals.mjs
scripts/read-patterns.mjs
scripts/measure-figures.js		 런타임 SVG 긴 문장·플레이스홀더·<desc> 누락 자동 린트, 디폴트 색상·타이포 기준 조회, 브라우저 DOM 충돌 측정 도구.
assets/pattern-library.json 런타임 검증된 기본 팔레트, 타이포 크기, 시각 구성요소 참조 데이터(문서 맥락에 맞춰 변주 가능).
version.json 버전 배포 판본 메타데이터(1.3.0). 설치기가 이 버전과 해시를 영수증에 기록합니다.
evals/feedback-index.json
evals/cases/{bad,good}/		 저장소 전용 실패 사례(BAD-001~005)와 성공 기준 사례(GOOD-001)를 보존하는 회귀 검증 아카이브.
